# API Health Probe

Monitor API endpoints with response-time charts, uptime percentage and alert configuration — a lightweight synthetic monitor for your services. Part of the Zion Tech Group App Network.

**Live app:** https://ziontechgroup.com/api-health-probe/

## About
API Health Probe is a free, browser-based tool from the [Zion App Network](https://ziontechgroup.com/apps/) (700+ open-source AI & IT ops apps). Category: **SRE & Reliability Tools**.

## Features
- Multi-endpoint uptime & latency checks
- Response-time charts and uptime percentage
- Configurable alert thresholds and escalation hints
- Exportable monitoring reports
