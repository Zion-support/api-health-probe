# API Health Probe

Monitor API endpoints with response-time charts, uptime percentage and alert configuration — a lightweight synthetic monitor for your services.

**Live app:** https://zion-support.github.io/api-health-probe/

## Features
- Multi-endpoint uptime & latency checks
- Response-time charts and uptime %
- Configurable alert thresholds
